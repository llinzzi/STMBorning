# STM32G030 MG90S舵机控制测试程序

## 功能说明

这是一个用于测试MG90S舵机的程序。当按下连接到PA0的按键时，会按照以下顺序执行：
1. **阶段1**: PA7舵机从0度移动到180度
2. **阶段2**: PB1舵机从0度移动到90度
3. **阶段3**: PB1舵机从90度回到0度
4. **阶段4**: PA7舵机从180度回到0度
5. 每个舵机回到0度后会关闭PWM输出，避免抖动

## 硬件连接

- **PA0**: 按键输入（外部中断触发，上升沿触发）
- **PA7**: 舵机1 PWM信号输出（TIM17_CH1）
- **PB1**: 舵机2 PWM信号输出（TIM3_CH4）
- **舵机电源**: 需要独立5V电源供电，GND与开发板共地

## 舵机规格（MG90S）

- 工作电压: 4.8V - 6V
- PWM频率: 50Hz (20ms周期)
- 脉宽范围: 
  - 0度: 0.5ms (500us)
  - 90度: 1.5ms (1500us)
  - 180度: 2.5ms (2500us)

## 程序特性

1. **PWM配置**:
   - 定时器: TIM17 (PA7), TIM3 (PB1)
   - 预分频器: 15 (16MHz / 16 = 1MHz)
   - 自动重载值: 19999 (1MHz / 20000 = 50Hz)
   - 初始占空比: 500 (对应0度)

2. **运动控制**:
   - 开机后两个舵机都保持0度位置
   - 按下PA0按键后，启动4个阶段的顺序运动：
     - **阶段1** (3.6s): PA7从0度移动到180度
     - **阶段2** (1.8s): PB1从0度移动到90度
     - **阶段3** (1.8s): PB1从90度回到0度
     - **阶段4** (3.6s): PA7从180度回到0度
   - 阶段3完成后关闭PB1的PWM
   - 阶段4完成后关闭PA7的PWM
   - 总运动时间: 约10.8秒
   - 移动速度: 1度/20ms

3. **程序逻辑**:
   - 使用状态机控制4个阶段的顺序运动
   - PA0上升沿触发EXTI中断，启动motion_stage=1
   - 主循环中每20ms更新一次角度（非阻塞式）
   - 每个阶段完成后自动进入下一阶段
   - 所有阶段完成后返回空闲状态(stage=0)

## 编译与烧录

使用CMake构建:
```bash
mkdir build && cd build
cmake ..
make
```

或使用CLion直接打开项目并编译。

## 注意事项

1. 舵机需要独立电源供电，不要直接从开发板取电
2. 确保舵机GND与开发板GND共地
3. 按键需要外部上拉电阻或使用带上拉的按键模块
4. 可以根据实际舵机调整脉宽范围（在tim.c的Servo_SetAngle和Servo2_SetAngle函数中）
5. 可以修改SERVO_UPDATE_INTERVAL来调整运动速度（默认20ms）
6. 可以修改switch语句中的目标角度来调整运动范围
7. 使用状态机和非阻塞延时，舵机运动更加流畅
8. 总运动时间: 180*20ms + 90*20ms + 90*20ms + 180*20ms = 10.8秒
9. 运动过程中再次按按键不会响应，需等待完成
