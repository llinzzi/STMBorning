# STM32G030 MG90S舵机控制测试程序

## 功能说明

这是一个用于测试MG90S舵机的简单程序。当按下连接到PA0的按键时，PA7连接的舵机会从0度平滑移动到180度。到达180度后会关闭PWM输出，避免舵机抖动。

## 硬件连接

- **PA0**: 按键输入（外部中断触发，上升沿触发）
- **PA7**: MG90S舵机PWM信号输出（TIM17_CH1）
- **舵机电源**: 需要独立5V电源供电，GND与开发板共地

## 舵机规格（MG90S）

- 工作电压: 4.8V - 6V
- PWM频率: 50Hz (20ms周期)
- 脉宽范围: 
  - 0度: 0.5ms (500us)
  - 90度: 1.5ms (1500us)
  - 180度: 2.5ms (2500us)

## 程序特性

1. **PWM配置**:
   - 定时器: TIM17
   - 预分频器: 15 (16MHz / 16 = 1MHz)
   - 自动重载值: 19999 (1MHz / 20000 = 50Hz)
   - 初始占空比: 500 (对应0度)

2. **运动控制**:
   - 开机后舵机保持0度位置
   - 按下PA0按键后，舵机从0度开始运动
   - 平滑移动到180度（约3.6秒）
   - 到达180度后关闭PWM输出，停止运动
   - 再次按下按键可重新从0度开始
   - 移动速度: 1度/20ms

3. **程序逻辑**:
   - PA0上升沿触发EXTI中断
   - 中断中重置舵机位置为0度，设置目标为180度
   - 主循环中逐步递增角度直到达到目标
   - 到达目标后关闭PWM输出，避免抖动

## 编译与烧录

使用CMake构建:
```bash
mkdir build && cd build
cmake ..
make
```

或使用CLion直接打开项目并编译。

## 注意事项

1. 舵机需要独立电源供电，不要直接从开发板取电
2. 确保舵机GND与开发板GND共地
3. 按键需要外部上拉电阻或使用带上拉的按键模块
4. 可以根据实际舵机调整脉宽范围（在tim.c的Servo_SetAngle函数中）
5. 可以修改HAL_Delay的延时值来调整摆动速度
6. 可以修改target_angle的值来调整目标角度（当前为180度）
7. 停止时关闭PWM输出可以有效防止舵机抖动和发热
