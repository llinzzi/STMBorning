# STM32G030 MG90S舵机控制测试程序

## 功能说明

duan这是一个用于测试MG90S舵机和蜂鸣器的程序。当按下连接到PA0的按键时，会按照以下顺序执行：
0. **开始**: 蜂鸣器播放生气的音乐（降调）
1. **阶段1**: PA7舵机从0度移动到180度
2. **阶段2**: PB1舵机从0度移动到90度
3. **阶段3**: PB1舵机从90度回到0度
4. **阶段4**: PA7舵机从180度回到0度
5. **结束**: 蜂鸣器播放欢快的音乐（升调）

## 硬件连接

- **PA0**: 按键输入（外部中断触发，上升沿触发）
- **PA6**: 蜂鸣器 PWM信号输出（TIM3_CH1）
- **PA7**: 舵机1 PWM信号输出（TIM17_CH1）
- **PB1**: 舵机2 PWM信号输出（TIM3_CH4）
- **舵机电源**: 需要独立5V电源供电，GND与开发板共地

## 舵机规格（MG90S）

- 工作电压: 4.8V - 6V
- PWM频率: 50Hz (20ms周期)
- 脉宽范围: 
  - 0度: 0.5ms (500us)
  - 90度: 1.5ms (1500us)
  - 180度: 2.5ms (2500us)

## 程序特性

1. **PWM配置**:
   - 定时器: TIM17 (PA7), TIM3 (PA6蜂鸣器, PB1舵机)
   - 舵机PWM: 预分频15, 自动重载19999 (50Hz)
   - 蜂鸣器PWM: 动态调整频率，支持50Hz-5kHz

2. **运动控制**:
   - 开机后舵机保持0度，蜂鸣器静音
   - 按下PA0按键后，执行完整序列：
     - **开始** (1s): 播放生气音乐 (G4→F4→D4→C4)
     - **阶段1** (3.6s): PA7从0度移动到180度
     - **阶段2** (1.8s): PB1从0度移动到90度
     - **阶段3** (1.8s): PB1从90度回到0度
     - **阶段4** (3.6s): PA7从180度回到0度
     - **结束** (0.9s): 播放欢快音乐 (C5→D5→E5→G5→A5)
   - 总时长: 约11.7秒

3. **程序逻辑**:
   - 使用状态机控制6个阶段（含音乐）的顺序执行
   - PA0上升沿触发EXTI中断，先播放生气音乐
   - 然后启动motion_stage=1，开始舵机运动
   - 主循环中每20ms更新一次角度（非阻塞式）
   - 阶段4完成后进入阶段5，播放欢快音乐
   - 所有阶段完成后返回空闲状态(stage=0)

## 编译与烧录

使用CMake构建:
```bash
mkdir build && cd build
cmake ..
make
```

或使用CLion直接打开项目并编译。

## 注意事项

1. 舵机需要独立电源供电，不要直接从开发板取电
2. 确保舵机GND与开发板GND共地
3. 按键需要外部上拉电阻或使用带上拉的按键模块
4. 蜂鸣器连接到PA6，支持无源蜂鸣器
5. 可以根据实际舵机调整脉宽范围（在tim.c的Servo_SetAngle和Servo2_SetAngle函数中）
6. 可以修改SERVO_UPDATE_INTERVAL来调整运动速度（默认20ms）
7. 可以修改tim.c中的angry_notes和happy_notes数组来自定义音乐
8. 使用状态机和非阻塞延时，舵机运动更加流畅
9. 总时长: 生气音乐(1s) + 舵机运动(10.8s) + 欢快音乐(0.9s) = 12.7秒
10. 运动过程中再次按按键不会响应，需等待完成
