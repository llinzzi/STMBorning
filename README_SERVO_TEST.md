# STM32G030 MG90S舵机控制测试程序

## 功能说明

这是一个用于测试MG90S舵机的简单程序。当按下连接到PA0的按键时，PA7连接的舵机会从0度平滑移动到90度。

## 硬件连接

- **PA0**: 按键输入（外部中断触发，上升沿触发）
- **PA7**: MG90S舵机PWM信号输出（TIM17_CH1）
- **舵机电源**: 需要独立5V电源供电，GND与开发板共地

## 舵机规格（MG90S）

- 工作电压: 4.8V - 6V
- PWM频率: 50Hz (20ms周期)
- 脉宽范围: 
  - 0度: 0.5ms (500us)
  - 90度: 1.5ms (1500us)
  - 180度: 2.5ms (2500us)

## 程序特性

1. **PWM配置**:
   - 定时器: TIM17
   - 预分频器: 15 (16MHz / 16 = 1MHz)
   - 自动重载值: 19999 (1MHz / 20000 = 50Hz)
   - 初始占空比: 500 (对应0度)

2. **运动控制**:
   - 每次按键按下，舵机从0度开始
   - 以1度/20ms的速度平滑移动到90度
   - 总运动时间约1.8秒

3. **中断处理**:
   - PA0上升沿触发EXTI中断
   - 中断回调中重置舵机位置并启动运动

## 编译与烧录

使用CMake构建:
```bash
mkdir build && cd build
cmake ..
make
```

或使用CLion直接打开项目并编译。

## 注意事项

1. 舵机需要独立电源供电，不要直接从开发板取电
2. 确保舵机GND与开发板GND共地
3. 按键需要外部上拉电阻或使用带上拉的按键模块
4. 可以根据实际舵机调整脉宽范围（在tim.c的Servo_SetAngle函数中）
