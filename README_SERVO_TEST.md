# STM32G030 MG90S舵机控制测试程序

## 功能说明

这是一个用于测试MG90S舵机的简单程序。开机后，PA7连接的舵机会自动在0度到180度之间来回摆动，并在0度和180度位置各停留3秒。停止时会关闭PWM输出，避免舵机抖动。

## 硬件连接

- **PA7**: MG90S舵机PWM信号输出（TIM17_CH1）
- **舵机电源**: 需要独立5V电源供电，GND与开发板共地

## 舵机规格（MG90S）

- 工作电压: 4.8V - 6V
- PWM频率: 50Hz (20ms周期)
- 脉宽范围: 
  - 0度: 0.5ms (500us)
  - 90度: 1.5ms (1500us)
  - 180度: 2.5ms (2500us)

## 程序特性

1. **PWM配置**:
   - 定时器: TIM17
   - 预分频器: 15 (16MHz / 16 = 1MHz)
   - 自动重载值: 19999 (1MHz / 20000 = 50Hz)
   - 初始占空比: 500 (对应0度)

2. **运动控制**:
   - 开机后舵机自动开始运动
   - 从0度平滑移动到180度（约3.6秒）
   - 到达180度后关闭PWM输出，停留3秒
   - 反向移动回0度（约3.6秒）
   - 到达0度后关闭PWM输出，停留3秒
   - 持续往复摆动
   - 移动速度: 1度/20ms

3. **程序逻辑**:
   - 使用方向标志控制摆动方向
   - direction=1时从0度向180度移动
   - direction=0时从180度向0度移动
   - 到达边界后关闭PWM输出，使用计数器控制停留时间（默认3000ms）
   - 停留结束后重新启动PWM并切换方向

## 编译与烧录

使用CMake构建:
```bash
mkdir build && cd build
cmake ..
make
```

或使用CLion直接打开项目并编译。

## 注意事项

1. 舵机需要独立电源供电，不要直接从开发板取电
2. 确保舵机GND与开发板GND共地
3. 可以根据实际舵机调整脉宽范围（在tim.c的Servo_SetAngle函数中）
4. 可以修改HAL_Delay的延时值来调整摆动速度
5. 可以修改角度范围（0-180）来调整摆动幅度
6. 可以修改PAUSE_TIME宏定义来调整停留时间（在main.c中，单位ms）
7. 停止时关闭PWM输出可以有效防止舵机抖动和发热
